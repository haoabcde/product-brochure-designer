# 设计系统知识库（Design System）

本文件是产品手册设计的**判断依据**，不是模板。它蒸馏自三大设计传统与当代行业共识：

- **瑞士国际主义**（Josef Müller-Brockmann《Grid Systems in Graphic Design》）：网格、客观性、左对齐
- **Apple / Dieter Rams**：「Less, but better」、留白作为主动设计工具
- **原研哉 / MUJI**：「空」而非「简约」、「满代表廉价，空代表奢侈」
- **2025 行业趋势共识**：字体纪律、叙事弧、图像质量门槛

执行手册任务时，先通读本文件，再按 `style-directions.md` 选定方向，然后把原则**应用**到当前产品——不要机械复制任何固定版式。

---

## 1. 总纲：高级感从哪里来

高级感 = **克制** + **秩序** + **呼吸**。

- **克制**：元素少、颜色少、字体少、装饰零。每加一个元素都要问：拿掉它信息是否仍然完整？是，就拿掉。
- **秩序**：所有元素落在网格上，层级靠字号/字重/留白拉开，不靠颜色和装饰。
- **呼吸**：留白是被塑造的材料，不是剩下的空隙。读者眼睛需要停顿，停顿本身传递从容与自信。

> 原研哉：「简约透过去除来澄清，留白透过去除来邀请。」一份塞满的手册在说"我怕你觉得不值"；一份从容留白的手册在说"我对内容有信心"。

## 2. 页面与网格（Grid）

### 2.1 页面规格

- A4 竖版：210mm × 297mm，打印边距 0（出血由页面内部安全边距控制）。
- **安全边距 14–18mm**，任何文字不得进入边距区。出血图片可以满页，文字不可以。
- 页数：6 / 8 / 10 页（含封面封底）。信息量不够就做 6 页，不要注水。

### 2.2 网格纪律

- 底层用 **12 栏网格**推导分栏；实际内容只占 2–3 个活动栏（如 40/60、60/40、25/75）。
- **空间刻度**：所有间距从 `{2, 4, 6, 10, 16, 24, 40}mm` 中选取，禁止出现 7mm、13.5mm 这类任意值。这就是 Müller-Brockmann 的 baseline grid 思想在 mm 单位下的实现。
- 同一类元素（页眉标签、标题、页脚）在全书所有页面上位置完全一致——读者无意识地依赖这种一致性。
- 页面上的每个元素都必须能与网格对齐；对不齐的元素说明它不该在那里。

### 2.3 每页一个焦点

一页只表达一件事。一页最多一张主图、一个大标题、一组正文。如果一页想讲三件事，拆成三页，或者砍掉两件。

## 3. 字体排印（Typography）

### 3.1 字体家族：最多 2 个

- **标题衬线 + 正文黑体**（推荐，杂志感）：标题 `"Noto Serif SC", "Source Han Serif SC", serif`；正文 `"PingFang SC", "Microsoft YaHei", "Noto Sans SC", sans-serif`。
- **全家黑体**（现代/科技感）：标题和正文同一黑体家族，靠字重和字号拉开层级。
- 衬线 = 传统、文化、人文、可信；黑体 = 现代、科技、效率。**不要混用第三种字体**，包括英文字体——英文随中文字体走即可。

### 3.2 字级阶梯（modular scale，比例 ≈1.5）

| 角色 | 字号 | 说明 |
|---|---|---|
| 封面主标题 | 30–36pt | 全书最大，只出现一次 |
| 页面标题 | 22–27pt | |
| 出血页声明句 | 24–30pt | 介于封面与页题之间 |
| 小节标题 | 11–13pt | |
| 正文 | 9–10.5pt | 中文正文不要低于 9pt |
| 辅助/脚注 | 7.5–8.5pt | 页脚、免责声明、图注 |
| 眉标（label） | 7.5–8pt | 全大写英文或四字以内中文，字距 +2～2.5px |

- 中文正文行高 **1.7–1.9**；标题行高 1.2–1.35。
- 层级靠**字号 × 字重 × 留白**三者的组合拉开；不靠颜色变化（颜色只有 accent 一处用法）。
- 对齐：西文习惯左对齐不齐右（flush left, ragged right）；中文正文可两端对齐，标题一律左对齐。**禁止居中排大段正文**。

### 3.3 文字即图形时的规则

- 大标题压在图片上：必须有渐变遮罩过渡，且文字区对应的图像区域要相对安静（见 §5.3）。
- 序号数字（01 / 02 / 03）可以放大到 20–24pt 并用 accent 色——这是允许的少数"装饰性大字"。

## 4. 色彩纪律（Color）

### 4.1 四色槽位，不可增加

`background`（页面底色）· `ink`（主文字）· `accent`（强调）· `overlay`（遮罩/深页底色）。`paper`（卡片底）只允许是 background 与纯白之间的邻近色。

### 4.2 60-30-10 配比

- **60%** 背景色主导页面（浅灰白或深色之一，全书统一）；
- **30%** ink 文字与结构；
- **10%** accent——只用于眉标、序号、时间轴节点、细线，**永远不做大面积填充**。

### 4.3 配色推导方法（不查表，会推导）

从产品气质出发选 accent 的色相，然后**降低饱和度、加深明度**——廉价感几乎总是来自高饱和亮色：

- 科技 → 冷蓝/蓝紫，压暗：`#2D6CDF` 而非 `#00BFFF`
- 自然/研学 → 苔绿/深青：`#3E7A5E` 而非 `#7CFC00`
- 文化/ heritage → 赭石/砖红：`#A65A3A`
- 高端/深色向 → accent 可用金铜：`#B08D57`

overlay 与 ink 用同一色相族的极深色（如藏青 `#102A43`），不要用纯黑 `#000`——纯黑在印刷和屏幕上都显得死。

### 4.4 深色页与浅色页的节律

全书以浅色页为主时，深色页（overlay 底）只用于封面、故事页、尾页这三类"情绪页"，浅色页承载信息。反过来（深色主导）时，规格页/行程页必须是浅色的——**深色底上排密集信息的可读性代价很高**。

## 5. 图像处理（Image）

### 5.1 选图：真实 > 好看

- 摄影优于插画，真实场景优于摆拍渲染。官方图片（公众号/官网）优先于一切图库。
- 拒绝：水印、图上叠大字、低分辨率、过饱和、廉价素材感、AI 生成图冒充真实场景。
- 封面/全出血图宽 ≥2400px；栏内图 ≥1800px。

### 5.2 裁切：永远 cover，永不拉伸

所有图片 `object-fit: cover` 等比居中裁切。宁可裁掉边缘，不可改变宽高比——拉伸变形的照片是廉价感的头号来源。

### 5.3 文字压图：渐变遮罩是唯一正确姿势

- 封面/出血页：`linear-gradient` 从透明到 overlay 85–92%，文字落在渐变最深的区域。
- 栏内小图不需要遮罩，但可以统一叠一层 10–15% 的 overlay 压色——**同一本书里所有照片叠同样的压色，能把来源不一的照片统一成一套视觉**。
- 禁止：文字直接压在明亮杂乱的图像区域上、给文字加阴影/描边来"抢救"可读性（这是下游修补，上游应该换图或加深遮罩）。

### 5.4 一图胜多图

一页放 4 张小图 = 廉价目录感。一页放 1 张有张力的大图 + 克制文字 = 高级感。图多的时候，分到多页去。

## 6. 留白与节律（Whitespace & Rhythm）

- 「满代表廉价，空代表奢侈。」每页至少 **35% 的面积是空白**（含边距）。写完一页先自查这个比例。
- 信息密度页（规格表、行程、列表）之后，跟一页呼吸页（大图少字）——读者的翻页节奏需要"密-疏-密-疏"。
- 元素之间的间距 ≥ 元素内部的间距（如列表项间距 > 行距），视觉上才成组。
- 砍掉一半文字是改善任何一页的最快手段。正文每段不超过 4 行；全书介绍性正文 250–350 字封顶。

## 7. 页面叙事弧（Narrative Arc）

10 页（或 8/6 页按此比例压缩）的推荐叙事结构：

| 页 | 角色 | 内容 | 气质 |
|---|---|---|---|
| 1 | 钩子 | 封面：一张主图 + 产品名 + 一句话 | 情绪 |
| 2 | 语境 | 这是什么、为什么存在（介绍） | 信息·疏 |
| 3 | 价值 | 核心价值点 2–3 条 | 信息 |
| 4–5 | 展开 | 内容模块/行程/流程 | 信息·密 |
| 6 | 呼吸 | 全出血故事页：一句有张力的话 | 情绪 |
| 7–8 | 证据 | 规格、成果、数据、保障 | 信息·密 |
| 9 | 高潮 | 全书最想让人记住的一页 | 情绪 |
| 10 | 行动 | 尾页：联系方式 + 免责 | 收束 |

- **高潮页放倒数第二页，行动页放最后**——情绪顶点之后立刻给联系方式，是行业共识的转化结构。
- 页脚只放品牌名 + 页码，7.5–8pt，60–70% 不透明度。页码位数不足补零（02、03）。

## 8. 反模式清单（生成后逐项自查）

- [ ] 一页超过一张主图 / 超过一个大标题
- [ ] 文字压图但无遮罩，或文字落在杂乱图像区
- [ ] 图片被拉伸变形（未用 cover）
- [ ] 任意间距值（不在 2/4/6/10/16/24/40mm 刻度上）
- [ ] 第三种字体、第五种颜色出现
- [ ] accent 色被大面积填充
- [ ] 大段文字居中
- [ ] 某页空白率 <35%
- [ ] 正文单段 >4 行 / 全书文字注水（为凑页数而写）
- [ ] 纯黑 `#000`、高饱和亮色
- [ ] 编造事实（缺失事实必须是 `【待确认】`）
