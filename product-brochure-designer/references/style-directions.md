# 风格方向（Style Directions）

六个经过验证的风格方向，各自对应一种**读者与场景**。选定后按 `design-system.md` 的纪律执行——方向决定"气质与色板推导"，纪律决定"好不好看"。可有意识地混合（如 editorial 字体 + dark-bleed 封面），但基调方向只能有一个。

> **核心原则：风格由读者决定，不由产品决定。**
> 同一个产品（如高校研学），给企业管理层的版本和给青少年与家长的版本，风格必须不同。
> 先问"这本手册给谁看、要促成什么行动"，再问"产品是什么"。

---

## 1. editorial · 杂志编辑风（默认）

- **气质/读者**：安静、建筑感、大留白，像好杂志而非宣传单。面向知识型决策者（高校、文化机构、B2B）。
- **色板**：bg 浅灰白（`#F4F6F8` 量级），ink 藏青黑，accent 品牌色压暗，overlay 与 ink 同族深色。
- **字体**：标题衬线 + 正文黑体（最经典的杂志配对）。
- **网格/图像**：分栏为主（图 40%/文 60%），照片统一 10–15% 压色，封面渐变遮罩。

## 2. swiss · 瑞士国际主义

- **气质/读者**：精密、客观、理性。面向技术/专业读者——工程师、采购、评审专家，他们要证据和参数。适合科技、工业、投标。
- **色板**：bg 近白，ink 深灰黑，accent 冷蓝压暗（`#2D6CDF` 量级），几乎无暖色。
- **字体**：全家黑体，层级全靠字重字号；眉标全大写加宽字距。
- **网格/图像**：最严格——所有元素落格，细线（0.4–0.75pt）做结构分割，拒绝圆角与阴影；摄影客观化，出血页极少。

## 3. muji · 东方空无

- **气质/读者**：极端留白、低饱和、安静到近乎无设计。面向生活美学消费者。适合生活方式、手工艺、生态、食品、文创、康养。
- **色板**：bg 米白/纸白（`#F7F5F0` 量级），ink 暖灰黑，accent 大地色（苔绿/赭石/灰褐），全低饱和。
- **字体**：标题细衬线，正文黑体但整体字级偏小半级，行高 1.85–1.95。
- **网格/图像**：留白 ≥45%；内容放页面中下区域，上部留空（地平线构图）；低饱和自然光照片，宁裁大图留氛围。

## 4. dark-bleed · 暗色沉浸

- **气质/读者**：高级、电影感、产品如展品。面向高端客户与需要被"震撼"的决策者。适合高端制造、旗舰产品、品牌册。
- **色板**：bg 与 overlay 同为深色系（藏青/炭黑/深墨绿），ink 反白，accent 可金铜或品牌亮色（仍只用 10%）。
- **字体**：标题衬线反白最有质感；正文 10pt 反白行高 1.8。**信息密集页必须切浅色底**。
- **网格/图像**：出血页占一半以上，浅底信息页用同 accent 保持血缘。图像质量门槛最高——深色放大一切缺陷。

## 5. heritage · 人文温润

- **气质/读者**：纸感、温润、时间感，像文物出版社的书。面向文化消费者。适合历史、非遗、文博、老字号、茶酒。
- **色板**：bg 暖米白（`#F5F1E8` 量级），ink 深棕黑，accent 砖红/赭石/靛蓝（`#A65A3A` / `#3D5166`），overlay 深棕。
- **字体**：标题衬线必选；正文短段可用衬线，长段用黑体保可读性。
- **网格/图像**：古典分栏（1/3 图 2/3 文）；细线 0.4pt ink 30% 透明；暖调统一压色，材质特写（纸/木/陶/织物）优先。

## 6. youth · 青少明快风

- **气质/读者**：明亮、亲和、有朝气但**依然克制**——明快 ≠ 花哨，活泼 ≠ 廉价。面向青少年学生、家长、老师。适合 K12 研学、夏令营、亲子、招生。
- **色板**：bg 纯白或极浅暖白，ink 深青黑，accent **亮一度但不许艳**——提高明度、保持中低饱和（`#3A8DDE` 明亮蓝 / `#E8833A` 活力橙 / `#45A37A` 青绿）。
- **字体**：标题**黑体加粗**（衬线对青少年太教科书），字号整体 +0.5–1 级；正文 10.5–11pt 行高 1.85；单段 ≤3 行。
- **网格/图像**：图可占 50–60%；序号/节点更大；允许 accent 小色块做标签底（单块不超过指甲盖）。真实的学生活动照片优先，拒绝摆拍与 clipart——青少年手册的廉价感主要来自 clipart 而非色彩。
- **分界线**：如果家长看了觉得"像培训机构传单"，就是越界了。

**研学手册的页面角色参考**（按叙事弧套用）：

| 页面角色 | 要点 |
|---|---|
| 封面 | 一张场景主视觉 + 主标题 + 一句副标题；不要同时堆卖点、时间、地点 |
| 概览 | 一句核心定位 + 3 个卖点 + 少量关键数字 |
| 课程/模块 | 每页只突出一个主题；左逻辑右场景；避免一排同尺寸卡片 |
| 行程 | 时间轴；时间/活动名称固定对齐；不要每个时间点配小图 |
| 导师/机构 | 一张高质量主图 + 简短身份 + 2–3 项代表成果；不写简历式长文 |
| 成果 | 大数字、作品照片、具体产出；禁止只写"提升能力、开阔视野"式空话 |

## 选择方法（按顺序回答三个问题）

1. **读者是谁？**（决定方向）
   - 企业/机构决策者 → editorial、swiss、dark-bleed
   - 青少年 + 家长 → youth
   - 生活美学消费者 → muji
   - 文化爱好者 → heritage
   - 混合读者时，以**掏钱做决定的那个人**为准（如研学手册：家长是决策者，但阅读体验要兼顾学生——youth 方向、内容措辞兼顾）。
2. **手册要促成什么行动？**（决定叙事重心）
   - 信任与签约 → 证据页加重（swiss/editorial）；报名与咨询 → 价值与氛围页加重（youth/muji）；品牌印象 → 情绪页加重（dark-bleed）。
3. **产品与品牌气质是什么？**（只做微调，不做决定）
   - 产品类别只影响色板推导与图像选择，**不推翻第 1 问定下的方向**；品牌主色按方向规则压暗或提亮推导 accent。

拿不准就用 editorial——最不容易出错，且与中文衬线标题天然契合。
